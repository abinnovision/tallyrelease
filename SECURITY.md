# Security policy

## Supported versions

tallyrelease is in beta. Security fixes are released for the latest `0.x` minor version only.

## Reporting a vulnerability

Do not open a public issue. Report vulnerabilities privately through [GitHub security advisories](https://github.com/abinnovision/tallyrelease/security/advisories/new) or by email to info@abigroup.io.

Include the affected version, a description of the issue and steps to reproduce it. We acknowledge reports within a few working days and keep you updated until a fix is released.

tallyrelease runs in CI with a forge token that can push branches and tags and create pull requests and releases. Issues that let repository content or config escalate what that token does are in scope.
