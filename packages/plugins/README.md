# @tallyrelease/plugins

Built-in ecosystem plugins (`node`, `php`, `kustomize`, `dart`) of [tallyrelease](https://github.com/abinnovision/tallyrelease). They are pure: files are read only through the `Ctx` that `@tallyrelease/core` injects.

Most users want [`@tallyrelease/cli`](https://www.npmjs.com/package/@tallyrelease/cli) instead, which bundles these plugins.
